## 📱 راهنمای استفاده در نرم‌افزارها

### 🔹 v2rayNG (اندروید)
1. منوی گوشه (سه خط) را باز کرده و وارد **Subscription group setting** شوید.
2. روی علامت **+** در بالای صفحه بزنید.
3. در قسمت **remarks** یک نام دلخواه (مثلاً Kourosh Asli) بنویسید.
4. در کادر **Optional URL** یکی از لینک‌های بالا را پیست کنید و تیک بالای صفحه را بزنید.
5. به صفحه اصلی برنامه برگردید، منوی سه‌نقطه را باز کرده و **Update subscription** را لمس کنید.

### 🔹 Hiddify / Streisand / Nekoray / v2rayN
- کافیست لینک سابسکریپشن بالا را کپی کرده و در برنامه گزینه **Add Profile / Add from Clipboard** را انتخاب کنید.
